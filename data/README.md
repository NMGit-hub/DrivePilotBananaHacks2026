# data/

Local recordings. Everything below this folder except this file is gitignored.

- `videos/`: recorded drives (`.mp4`/`.mov`). Dev clips from BDD100K live in subfolders here.
- `gps/`: GPX tracks recorded alongside drives (GPSLogger on Android, 1-second interval).
- `audio/`: recorded or generated audio (e.g. in-car noise for wake-word tuning).
